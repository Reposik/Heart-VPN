## 🚀 ИНСТРУКЦИЯ ПО УСТАНОВКЕ (INSTALLATION)

Все официальные сборки хранятся в директории `App/`. Выбери свою платформу:

### 💻 Для Windows (PC)
1. Перейди в папку [App/](./App)
2. Скачай файл **`HeartVPN_PC.exe`**.
3. Запусти его (при первом запуске он автоматически скачает ядро Xray и настроит систему).
4. Выбери страну и нажми **INITIALIZE**.
   * *Примечание: Если Windows выдаст предупреждение, нажми "Подробнее" -> "Выполнить в любом случае".*

### 📱 Для Android (Mobile)
1. Перейди в папку [App/](./App)
2. Скачай файл **`HeartVPN_Mobile.apk`**.
3. Установи его на свой смартфон.
4. Выбери узел связи и нажми **ENGAGE**.
   * *Для работы требуется установленное ядро v2rayNG (приложение предложит импортировать конфиг автоматически).*
